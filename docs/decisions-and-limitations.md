# Decisions and Limitations

## 스프레드시트에서 웹앱으로 전환

공유 시트는 빠르게 시작할 수 있었지만, 데이터가 쌓일수록 조회·수정·마감 기준을 한눈에 보기 어려웠습니다. 폼을 하나 더 만드는 대신 역할별 사용자 흐름과 단일 데이터 원천을 가진 웹앱으로 전환했습니다.

## 기능 범위를 줄인 사례

카카오 1:1 자동 연락을 검토했지만, 필요한 연락 방식이 API 구조와 맞지 않았습니다. 연동을 구현했다고 주장하지 않고 엑셀 메시지 생성 방식으로 대체했습니다.

## 아직 해결하지 않은 문제

- 사용자별 세부 행 단위 권한(RLS)
- 대용량 기록을 위한 서버 집계
- 엑셀 업로드
- 학부모 확인서와 학생 신고의 스키마 통일
- 다운로드 필드명 정합성

## 소스 공개 상태

운영 앱은 Base44에서 제작·배포했습니다. 현재 사용 중인 플랜은 GitHub 소스 내보내기를 지원하지 않으므로, 이 저장소에는 검증 가능한 설계·운영 근거와 공개 가능한 문서만 담습니다.
